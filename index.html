    快速跳轉章節 Quick Jump：

    01 平台定位、快速入門與 BYOK 金鑰安全設定 (Quick Start & BYOK Security)

    TONY Skill Factory v2.0 將「Word 規範書、Skill 樣板、Validator 驗證器、Migrator 遷移器」四件套整合於瀏覽器中。使用者無須安裝 Python 環境，即可完成 AI 技能包從建立、解析、驗證、修復、遷移到標準 ZIP 封裝下載的全生命週期管理。

    Step 1：一鍵體驗範例

    初次使用可於 M01 總覽儀表板 (Dashboard) 點擊「載入黃金標準範例 (96分 Pass)」或「載入待修復測試範例」，立即體驗驗證與打包流程。

    Step 2：設定 BYOK 金鑰 (選填)

    點擊右上角 BYOK 金鑰按鈕 或進入 Settings & BYOK Key，輸入您的 Google Gemini API Key。金鑰僅存於目前分頁記憶體 (RAM)，關閉或重整網頁立即清除，絕不寫入資料庫。

    Step 3：端到端封裝匯出

    即使未輸入 API Key，系統內建之「6G 確定性樣板引擎」、「百點規則驗證器」與「JSZip 封裝器」仍可 100% 獨立運作並匯出標準可解壓 ZIP。

    02 TONY 6G 標準工作流程與狀態機 (TONY 6G Workflow & State Machine)

    所有符合 v2.0 規範的技能包，皆須具備以下六大階段與標準狀態轉換（INIT → INPUT_READY → PLAN_APPROVED → EXECUTING → VALIDATING → DELIVERED）：

    G1 Goal｜任務目標辨識

    界定技能包要解決的核心商業問題、目標受眾與明確可量化之成功條件。

    G2 Guide｜三模式引導

    提供 A 引導模式 (Guided)、B 快速模式 (Fast)、C 專家模式 (Expert) 滿足不同熟練度使用者。

    G3 Gather｜輸入收集與事實分離

    收集必要參數，嚴格區分「已知事實 [FACT]」與「推論假設 [ASSUMPTION]」，杜絕 AI 幻覺。

    G4 Generate｜產出與工具契約

    生成標準 SKILL.md、references/tony-manifest.yaml 並宣告 T01–T08 工具契約。

    G5 Guard｜雙軌品質與安全驗證

    執行確定性結構檢查與 AI 語意審查，阻斷 ../ 路徑穿越、金鑰外洩與偽造實體檔案宣稱。

    G6 Give｜成果封裝交付與缺口說明

    打包標準 ZIP 供下載，並誠實揭露未啟用工具之替代執行方案。

    03 八大核心模組標準操作指南 (M01–M08 Modules Step-by-Step SOP)

    M01 總覽儀表板 (Dashboard Overview)

    檢視技能總數、已達標可發布數 (90–100分)、待修復數與平均品質分。可一鍵載入標準黃金範例或缺陷案例。

    M02 技能建構器 (AI Skill Builder)

    輸入技能代碼 (如 TONY-43)、技術名稱 (須為 kebab-case 小寫連字號)、語意版本 (如 2.0.0)，勾選所需工具契約 (T01–T08)，點擊「依 6G 樣板即時生成」或「Gemini AI 深度生成」，即可產出完整三份核心檔案。

    M03 壓縮包解析器 (ZIP Inspector)

    上傳任何外部 .zip 技能包，系統會在前端沙盒計算 SHA-256 雜湊、展開目錄樹、靜態預覽文字，並自動攔截超過 20MB、超過 500 個檔案、巢狀壓縮或含 ../ 路徑穿越之危險檔案。

    M04 雙軌品質驗證器 (Skill Validator)

    分為兩階段：1. 執行確定性結構驗證（依七大維度 100 分制即時算出客觀分數並標示 Blocking Issues）；2. 執行 Gemini AI 語意品質評估（針對方法論深度提供審查建議，獨立標示不混充確定性分數）。

    M05 智慧缺陷修復 (AI Skill Repair)

    當技能分數未達 90 分或有阻斷問題時，點擊「生成標準結構修復草稿」，左側保留原版供對照，右側自動修正 kebab-case、移除危險路徑、補齊 YAML 與 6G 段落並自動升級小版本號，確認後點擊套用重驗。

    M06 舊版技能遷移器 (Skill Migrator)

    貼上舊版 v1.0 Prompt 或 OpenAI Custom GPT 指令，點擊「執行 v2.0 標準遷移轉換」，系統將 100% 保留原始專業方法論並重構為 6G 標準格式，同時產出遷移差異報告。

    M07 數位技能資產庫 (Skill Library)

    集中管理您儲存於 Firestore 的個人技能包資產（嚴格依帳號 UID 隔離保護隱私），支援關鍵字檢索與一鍵載回編輯器。

    Q1：收不到註冊驗證信或重設密碼信怎麼辦？
    系統於首次註冊與忘記密碼時皆會自動觸發 Firebase 認證信。若於收件匣未看到，請務必前往信箱的「垃圾郵件匣 (Spam / Junk)」確認並點擊驗證連結。
    Q2：如何使用管理者後台匯出 Excel 無亂碼 CSV 與 AI Word 分析報告？
    具備 admin 權限之帳號（如創作者專屬信箱 mindnodeai@gmail.com）登入後，點擊右上角「進入管理後台 Admin」：
    • 點擊「匯出 CSV」：系統已自動於檔案開頭寫入 \ufeff UTF-8 BOM 標記，直接以 Microsoft Excel 雙擊開啟即可正常顯示繁體中文。
    • 「AI 營運與會員成長分析報告」：選擇起始與結束日期後點擊「產出 AI 分析報告」，完成後點擊「輸出成 WORD 檔 (.doc)」即可下載正式排版文件。
